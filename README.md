<h1 align="center">Wolfgang</h1>

<p align="center">
Wolfgang is a private transcription app for Mac. It turns audio, video and meetings into timestamped transcripts right on your Mac, with speakers, summaries, translation and export to every common format. This repository is for releases only: each release here is offered to every copy of Wolfgang automatically.
</p>
